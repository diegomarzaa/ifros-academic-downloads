# IFRoS course downloads

[Open the course website](https://diegomarzaa.github.io/ifros-academic-archive/).

Download the combined offline ZIP or one course ZIP from the latest release. Extract the entire archive and open `index.html`. Each course ZIP includes its own website and files.

Courses: Autonomous Systems, Machine Learning, Multiview Geometry, Probabilistic Robotics and Robot Manipulation.

The website includes direct download links, collapsible topics, a large PDF reader and a timeline of published Moodle due dates. External services and Moodle submissions require internet access.

This repository stores downloadable snapshots. It does not contain Moodle credentials, grades or submitted work.
